# Pizza Sales Analysis Using SQL

## Project Overview
This project analyzes pizza sales data using SQL to uncover business insights related to customer ordering behavior, revenue generation, product performance, and sales trends.
The goal of this project is to demonstrate practical SQL skills that are commonly used in real-world data analytics and business intelligence roles.


## Why I Chose This Project
Food delivery and restaurant businesses generate large volumes of transactional data every day. Understanding customer preferences, peak ordering periods, and revenue drivers is essential for making informed business decisions.
I selected this project to strengthen my SQL skills and learn how data can be transformed into actionable business insights through structured querying and analysis.


## Business Objectives
The analysis aims to answer the following questions:

* How many orders were placed?
* How much revenue was generated?
* Which pizzas generate the highest revenue?
* Which pizza categories are most popular?
* What are the busiest ordering hours?
* How does revenue accumulate over time?
* Which products contribute most to business performance?

## Key Analyses Performed
1. Total number of orders placed.
2. Total revenue generated.
3. Highest-priced pizza identification.
4. Most frequently ordered pizza sizes.
5. Top-selling pizza types.
6. Category-wise sales analysis.
7. Hourly order distribution.
8. Average pizzas ordered per day.
9. Top pizzas by revenue.
10. Revenue contribution by category.
11. Cumulative revenue trend analysis.
12. Top-performing pizzas within each category using DENSE_RANK().


## Key Insights
* Certain pizza categories contribute significantly more revenue than others.
* Customer demand varies throughout the day, creating identifiable peak ordering hours.
* A small number of pizza types generate a large portion of overall revenue.
* Revenue trends can be tracked over time using window functions.
